## 📑 Visão Geral do Conteúdo

### Contexto e Conceito de Front-end
* **Front-end:** É a camada de uma aplicação responsável pela interface com o usuário, pela experiência do usuário ($UX/UI$) e pela comunicação com o back-end/servidores[cite: 3].
* **Relevância:** Frameworks modernas garantem aplicações web rápidas, organizadas e fáceis de manter, tornando-se um requisito estratégico no mercado[cite: 3].
* **Vanilla JS:** JavaScript puro (sem dependências externas), servindo como base fundamental para o uso de qualquer framework[cite: 3].

### Arquitetura de Software e Ciclo de Desenvolvimento
* Definição de escopo, prototipação e design de interface ($UX/UI$)[cite: 3].
* Uso de controle de versão (Git/GitHub) e integração de deploys automatizados (ex.: Vercel)[cite: 3].
* Conceitos de componentização, gerenciamento de estado e consumo de APIs em frameworks como React, Vue e Angular[cite: 3].

## 🛠️ Atividades da Aula

1. **Atividade 01 (Prática):**
   * Criar um projeto utilizando HTML, CSS e Vanilla JS[cite: 3].
